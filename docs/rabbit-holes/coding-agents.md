# Coding Agents

AI coding assistants, autonomous programming agents, and tools that write code so you can spend more time reviewing code you did not ask for.


## Tools & Resources

- **[continue](https://github.com/continuedev/continue)** `⭐ 32.9k` Continue is an open-source CLI that runs source-controlled AI checks as enforceable CI status checks on pull requests. <details><summary>More about</summary>

  It lets teams codify review policies (security, style, conventions) as repo-owned agent/check definitions so PR feedback is consistent and automated.

  _Now your code review can fail because a markdown file decided your PR “looks risky,” and you get to debug the diff suggestion like it’s a flaky unit test with opinions._
